# Mason Maier — IST Portfolio

A responsive portfolio for an Information Science & Technology student in Milwaukee, Wisconsin, focusing on business/systems analysis, databases, and practical IT.

## Preview and deployment

Open `index.html` locally to preview. To deploy with GitHub Pages: upload **the contents of this ZIP** (not the ZIP itself) to the repository root, then use repository Settings → Pages → Deploy from a branch → `main` → `/ (root)`.

## Files
- `index.html`: portfolio home with project filters and theme toggle
- `styles.css`: responsive design, layouts, illustrations
- `script.js`: accessible filter buttons and color-theme toggle
- `case-studies/support-ticket-analysis.html`: fictional self-study case study
- `case-studies/support-tickets.sql`: runnable MySQL 8 example with synthetic data
